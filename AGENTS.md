# Instruções do projeto

Leia `DESIGN.md` antes de alterar qualquer tela. Preserve o modo local-first: sem login, sem senha, sem Supabase, sem API remota e sem sincronização automática. Dados financeiros ficam no IndexedDB; backups JSON nunca devem ser adicionados ao Git. Siga o escopo `app` e as regras Hallmark de tokens, foco visível, controles acessíveis, responsividade e estados. Rode `node --check` nos arquivos JavaScript e mantenha os workflows de qualidade.

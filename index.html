Como o Ray guarda suas informações nesta versão.

INFORMAÇÕES DO APLICATIVO

Seus registros ficam no navegador deste aparelho.

O Ray não possui conta de usuário nem sincronização financeira em nuvem. Os lançamentos, cartões, parcelas, contas e metas são guardados no IndexedDB do navegador em que foram cadastrados.

O que é armazenado

  • Entradas, despesas, categorias, datas e observações.
  • Nome dos cartões, instituição, bandeira e, se informado, apenas os quatro últimos dígitos.
  • Compras parceladas, contas a pagar, metas e contribuições.
  • Preferência de tema, armazenada separadamente no navegador.

Onde os dados ficam

Os registros financeiros são gravados no IndexedDB do perfil do navegador utilizado. O GitHub Pages entrega os arquivos públicos do Ray, mas o código do aplicativo não envia os registros financeiros ao GitHub nem a um servidor de sincronização.

Qualquer pessoa que abra o endereço pode utilizar sua própria cópia local. Os dados não são compartilhados automaticamente entre iPhone, computador ou navegadores diferentes. Pessoas que utilizem o mesmo aparelho e o mesmo perfil do navegador podem ter acesso aos registros locais.

Backups e perda de dados

O backup é exportado em arquivo JSON sem criptografia criada pelo Ray. Guarde-o em local privado e não compartilhe o arquivo. Limpar os dados do Safari, trocar de perfil ou perder o aparelho pode apagar os registros. Antes de trocar de dispositivo, exporte o backup no aparelho antigo e restaure-o no novo.

Uso offline

O Service Worker guarda arquivos da interface para facilitar a abertura de recursos já carregados. Esse cache não é o banco de dados financeiro. O aplicativo não acessa automaticamente contas bancárias nem confirma transações; os dados são informados manualmente.
